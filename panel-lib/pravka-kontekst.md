# Правка: контекст величины

Замер 01.09.2026. Шесть проекций по 146 величинам трёх переведённых стендов
(gorizont, diagonal, obtekanie). Проекция = вопрос, на который величина
должна уметь ответить о себе.

```
проекция                        чем задаётся            названо
пространство — ГДЕ действует    gde                     2 из 146     1%
система — НА КАКОМ УРОВНЕ       опора доли             18 из 146    12%
время — КОГДА меняется          время / кривая         24 из 146    16%
отношения — ОТНОСИТЕЛЬНО ЧЕГО   острота / ход           0 из 9       0%
условие — ПРИ КАКОМ ПОРОГЕ      порог                   1 из 146     1%
фаза — КАКОЙ РОД ПОВЕДЕНИЯ      выбор / двоичное       20 из 146    14%
```

Пять проекций из шести показывают одну дыру с разных сторон: величина не
сообщает своего контекста. Панель знает «сколько» и не знает «чего и где».
Точечной работой это не видно — в каждой отдельной панели всё в порядке.

Ниже три починки, которые окупаются. Остальные три проекции оставить
счётчиками без требований: цифра копится, решение по ней позже.

## Чего НЕ чинить

Две находки первого захода снялись при чтении кода:

**Датчик на таблицу уже есть и работает.** `nuzhno` против `zrya` в конце
`izObyavleniya` различает вынужденную перебивку от осознанного сужения,
и печатает: «из таблицы N · сужено по смыслу N · таблица не вместила N».
Цифра «69% перебивают границы» сама по себе ничего не значит — механизм
её уже раскладывает.

**Претензия «доля без опоры» уже стоит.** Не хватает только реакции на
`'своё'` — см. починку 2.

## Починка 1. Опора у отношения

`panel-lib/obyavlenie.js`, TABLICA.

Тип «доля» опору требует жёстко: в комментарии написано, что доля без
ответа «от чего» не доля. У «остроты» и «хода» поля опоры нет вовсе, хотя
они меряют то же самое — положение на градиенте относительно чего-то.
Девять величин меряют отношение, ни одна не называет, к чему.

Опоры сняты с фактического употребления этих девяти, не придуманы:

| опора | что значит | величины |
|---|---|---|
| `ось` | расстояние до объявленной оси | textSharp, textFlow, numSharp, numFlow, rectSharp, rectFlow |
| `место` | позиция в потоке или ленте | compWave, compTypeJit |
| `фаза` | положение внутри самого перехода | compTypeDur |

Три опоры на девять величин. Список открытый: неизвестное имя даёт
претензию, и по её росту видно, что опор не хватает.

**Реализация.** Пометить типы в TABLICA и проверить в цикле сборки — рядом
с тем местом, где сейчас проверяется доля (около строки 202):

```js
'острота': { organ: 'слайдер', ot0: 0, do: 1, edinica: '',
             trebuet: 'датчик', otnositelno: true },
'ход':     { organ: 'слайдер', ot0: -1, do: 1, edinica: '',
             trebuet: 'датчик', otnositelno: true },

var OPORY_OTNOSHENIYA = ['ось', 'место', 'фаза', 'сосед', 'объект', 'край'];

if (baza.otnositelno) {
  if (!o.ot) pretenzii.push(tip + ' без опоры: ' + klyuch + ' — относительно чего?');
  else if (OPORY_OTNOSHENIYA.indexOf(o.ot) < 0)
    pretenzii.push('опора отношения «' + o.ot + '» не из свода (' + klyuch + ')');
}
```

**Границы опора НЕ трогает.** У доли опора даёт диапазон и единицу, здесь
она только называет. Острота остаётся 0…1 при любой опоре — иначе поедут
все девять существующих величин.

Значение кладётся в карту рядом с `sekciya`, чтобы ревизия его видела:
`karta.opora[klyuch] = o.ot`.

```js
было:  ['textSharp', 'Острота', 'острота', { shag: 0.05 }]
стало: ['textSharp', 'Острота', 'острота', { ot: 'ось', shag: 0.05 }]
```

Обратная совместимость полная: девять величин начнут печатать претензию,
работать не перестанут.

## Починка 2. «Своё» перестаёт быть бесплатным

`panel-lib/obyavlenie.js`, OPORY.

`'своё'` помечено в коде как свалка, и при этом проходит как законная
опора: претензия `!o.ot` на него не срабатывает. Сейчас там сидит
**14 долей из 32** — 44% всех долей не называют опоры.

```
gorizont   naborFront   Фронт перебора            katMasht    Каталог: масштаб
           naborFoto    Сдвиг картинки подписи    katTusk     Каталог: ненаведённые
           maskaSdvig   Врезка: сдвиг строк       katPerekr   Каталог: очередь движений
           vspDolya     Вспышка: доля слов        wheel       Колесо
diagonal   rectStretch      Плашки цифр: длина    textRectLeft  Плашки текста: слева
           textRectStretch  Плашки текста: длина  hexTone       Звук: тон
           textRectH        Плашки текста: высота speed         Скорость
```

**Реализация.** Одна сводная претензия вместо четырнадцати отдельных —
четырнадцать строк шума в консоли прочитаны не будут:

```js
// рядом со счётом nuzhno/zrya
var svalka = (zakon || []).filter(function (s) {
  return s[0] !== 'h' && s[2] === 'доля' && s[3] && s[3].ot === 'своё';
}).map(function (s) { return s[0]; });
if (svalka.length) {
  pretenzii.push('доля от «своё» у ' + svalka.length + ' законов — опора не названа, ' +
                 'границы взяты общие 0…100%: ' + svalka.join(', '));
}
```

**Менять опору в стендах отдельным решением, не этой правкой.** Смена
`'своё'` на настоящую опору двигает границы (своё 0…100, колонка 0…200),
и стенд поедет. Каждую из четырнадцати надо смотреть глазами: назвать
опору и одновременно закрепить фактические границы через `ot0`/`do`.

## Починка 3. Фаза гасит мёртвые ручки

`panel-lib/obyavlenie.js` + `panel.js`.

Двадцать переключателей (`выбор`, `двоичное`) меняют род поведения.
После переключения панель показывает все ручки, включая те, что в этой
фазе ничего не делают. Приём в стендах уже есть: gorizont прячет ручки
неработающей стороны каталога вручную через `hidden`, и в `panel.js`
про это написан комментарий у `st-vne`. Не хватает способа сказать то же
самое в объявлении.

**Синтаксис.** Поле `pri` — величина живёт, пока условие верно:

```js
pri: 'hexSnd'                          // пока hexSnd истинно
pri: { hexSnd: false }                 // пока выключено
pri: { compType: 'волна' }             // при этом значении выбора
pri: { compType: ['волна', 'сдвиг'] }  // при любом из
['h', 'Звук', { pri: 'hexSnd' }]       // на всю секцию разом
```

Секционная форма работает как `gde`: строка наследует условие секции,
`pri: null` отписывает.

**obyavlenie.js.** В первом проходе (там же, где `pripisat`) собрать
`zhivet[klyuch] = условие`. Проверить, что ключ-хозяин объявлен в этом же
законе — иначе претензия, как с неизвестным местом:

```js
pretenzii.push('закон ' + klyuch + ' живёт при «' + hozyain +
               '», которого нет в объявлении');
```

Положить в карту: `karta.zhivet = zhivet`.

**panel.js, два места.**

1. `perestroitVid()` (около 597) — добавить третье слагаемое к `skryt`,
рядом с набором и местом:

```js
было:  var skryt = vneNabora || (svoi ? svoi.indexOf(r.dataset.k) < 0 : false);
стало: var skryt = vneNabora || (svoi ? svoi.indexOf(r.dataset.k) < 0 : false)
                             || !zhiv(r.dataset.k);
```

где `zhiv(k)` читает `StendPanel.karta.zhivet[k]` и сверяет с текущими `P`.
Величина без условия жива всегда.

2. `izmenilos(key)` (строка 90) — через неё проходит любая правка ручки.
Если `key` оказался хозяином чьей-то фазы, перестроить вид:

```js
function izmenilos(key) {
  save();
  if (hozyaeva[key]) perestroitVid();     // ← добавить
  if (typeof o.onChange === 'function') o.onChange(key, P);
  ...
```

Проверить видимость: `perestroitVid` объявлена ниже `izmenilos`. Если она
не поднимается в этот скоуп, взять ту же схему, что у `obnovitSostoyanie` —
переменная в общем скоупе, присваивание внутри.

**Осторожно.** Прятать классом `st-vne`, а не атрибутом `hidden`:
`hidden` занят самими стендами, два механизма на одном атрибуте подерутся.
Это уже написано в комментарии `panel.js` — правка обязана его соблюсти.

Секция, у которой все строки погасли, скрывается вместе с заголовком —
логика уже есть в `perestroitVid`, отдельно делать нечего.

## Проверка после правки

1. Консоль каждого из трёх стендов: претензий стало больше на ожидаемое
   число (9 по остроте/ходу + 1 сводная по «своё»), новых непонятных нет.
2. `gorizont` — ручная скрытая сторона каталога не подралась с `st-vne`.
3. `diagonal` — переключение композиции A–F гасит и возвращает ручки,
   счётчик в строке состояния сходится.
4. Три ширины 360 / 768 / 1440 плюс теснота — панель не поехала.
5. Значения в `localStorage` уцелели: погашенная ручка сохраняет своё
   значение и возвращается с ним.
