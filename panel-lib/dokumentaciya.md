# Библиотека панелей — карта документации

Точка входа для человека и опора агента-проводника (`~/.claude/agents/provodnik.md`).
Правило: знание живёт в источниках ниже, агент его не носит. Меняются инструкции —
правится эта карта и источники, агент остаётся прежним.

## Порядок чтения для новичка

1. `~/stendy/panel.js` — шапка файла: как подключить панель к стенду
   (`/panel.css` + `/panel.js` + `StendPanel.build({...})`), формат defs, темы.
2. `~/stendy/panel-lib/obyavlenie.js` — шапка + таблица: объявление величин
   вместо чисел (`zakon`), типы и их обязательства, опоры доли, шаг из
   диапазона, места (`mesta` + `gde`) и карта `StendPanel.karta`.
3. `~/.claude/skills/stend/references/panel.md` — свод: 15 принципов панели,
   таблицы «эффект → ручки», каталог органов по рельсам Ф/П/В.
4. `~/stendy/panel-lib.html` — живой каталог органов, покрутить руками
   (stendy.vercel.app/panel-lib).
5. Хранилище «02 Программа/Рабочее/ИТМО — Вёрстка/Приёмы панелей/» —
   карточка на каждый орган, с провенансом.
6. Хранилище «…/ИТМО — Вёрстка/Библиотека панелей — законы места (отчёт).md» —
   места, клик по макету, этаж инструмента, пробы.

## Контракты, о которые спотыкаются

- `/panel.js` грузится РАНЬШЕ органов `/panel-lib/*.js`: он создаёт
  `window.StendPanel` целиком, органы дописываются в него. Нарушение падает
  громко («StendPanel is not defined»).
- Оригиналы стендов не трогать: опыты в файлах-двойниках; бэкапы общих
  файлов в формате `panel.js.do-<что-было-до>`.
- Двойник сверяется по трём измерениям: состав панели, значения ручек,
  границы/шаг каждого слайдера. Совпадения состава мало.
- Тип величины не выдумывается: нет в таблице — доложить «тип не найден»,
  это сырьё для пополнения свода.
- `./publish.sh` из `~/stendy` публикует каждую правку; рабочий адрес
  stendy.vercel.app (стенды.0снова.рф лежит), страховка ocnova-lab.github.io.
  После публикации стенд сразу открывается в браузере.
- Диагностика на стенде: `StendPanel.pretenzii` (претензии свода),
  `StendPanel.karta.pokazat()` (места и замер), `?reset=1` (сброс настроек),
  `?nabor=имя` и `?mesto=Имя` (открыть суженным).

## Кто ещё есть

- Настройщик (`~/.claude/agents/nastroyshchik.md`) — собирает панель стенда
  из объявления сам; проводник учит и отвечает, сборку отдаёт ему.
- Линтер-хук (`~/.claude/hooks/stend-lint.py`) — претензии свода на каждую
  правку стенда: параметры без ручек, переломы вместо законов.
